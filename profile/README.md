# Charlee X

🚀 Full-stack software company building modern solutions for web, mobile, and AI.

Welcome to **Charlee X**, where we design, build, and share production-ready tools for developers, startups, and small businesses. From client projects to open-source utilities, everything we release is built with quality, speed, and scalability in mind.

---

## 🧠 What We Do

- 🔧 **Web Development** – React, Tailwind, Node.js
- 📱 **Mobile Apps** – React Native & Kotlin
- ☁️ **Cloud Infrastructure** – AWS Serverless (CDK, SST, DynamoDB, Lambda)
- 🤖 **AI Tools** – Chatbots, Assistants, and Automated Writers
- 🛠️ **Reusable Components** – Real-world tested UI & backend modules
- 💡 **Open Source Kits** – Clean, modern codebases to get you started fast

---

## 🌍 Projects You’ll Find Here

| Project | Description |
|--------|-------------|
| `charleex-landing` | Our main website and landing page infrastructure |
| `starter-kit-web` | A production-ready web app boilerplate using React + Tailwind + AWS |
| `chatbot-kit` | AI-powered WhatsApp/website chatbot framework using OpenAI + Lex |
| `blog-engine` | Headless blogging engine with comments, SEO, and markdown support |
| `ai-copywriter` | AI blog & social post generator used across our projects |
